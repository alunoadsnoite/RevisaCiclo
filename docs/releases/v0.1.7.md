# RevisaCiclo 0.1.7

- Editar o título ou a descrição preserva a data da próxima revisão.
- Conclusões repetidas não geram revisões pendentes duplicadas.
- Contadores de atraso usam a data atual ao voltar ao aplicativo.
- Interface em espanhol, incluindo os novos filtros e mensagens.
- Opções de apoio via Pix e GitHub Sponsors nas configurações.
- Testes automáticos e compilação Android em cada alteração.

VersionCode: 8. Validação em Motorola confirmada pelo autor em 22/11/2026.

Esta release publica código-fonte e metadados. O APK distribuído pelo F-Droid
é compilado e assinado pelo próprio catálogo; a disponibilidade da atualização
depende do processamento dele. Não inclui APK upstream assinado.
